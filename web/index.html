    默认自动执行的安全格式修正：

    1. 已有标签补尖括号、规范标签内空格

    句末标点仅豁免：任务类型、similarity_label、video_similarity_tag、audio_similarity_tag（含 task_type、subtask_type、similarity_tag、视听标签等已知同义字段）。其他非空段落需句末标点，内容为“无”也需补；仅当 } 位于段尾且无后续文字或句末标点时补外层句号；句中 } 后还有内容不补。

    符号配对不完整需人工核对；内容类别和包裹符号是否对应，由语义辅助复核，不自动改写人声或画面文字。任务类型和视听标签用 | 或 ｜ 拼接，例如人物参考|动态参考；实体/IP中的 / 不拆分。

    主体一致性底线：主体定义不能重号、编号需连续；总结和自然指令不能引用未定义主体；每个已定义主体都须在自然指令中明确引用。描述内引用不算重复定义。重复前缀、叠词、属性冲突仍不检查。
    底线通过的含义：通过上述格式、标签和主体规范检查。病句、词表之外的疑似错别字和画面事实由人工确认；语义辅助结果不作底线结论。跳过或解析失败不等于通过。
