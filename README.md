# Caption QA Agent · macOS 同事试用包

功能代码统一放在 `captionqa/`，测试放在 `tests/`，网页资源放在 `web/`。根目录的 `agent.py` 是统一入口；日常使用安装和启动按钮即可，保留整个文件夹。

这是当前Agent的完整源码运行包，包含浏览器拖拽质检、字段规范、问题ID名单、缺字段明细、人工审核与确认修改、修正副本和报告导出，并附两套独立Skill。它不是免安装的.app：首次使用需要 Python 3.10+、网络安装依赖；AI质检需要使用者自己的MiMo Token Plan密钥。

## 首次使用

1. **完整解压ZIP**，将 `CaptionQAAgent` 文件夹放到自己有写入权限的位置。保留所有文件，不在ZIP预览里直接运行。
2. 双击 **`安装环境.command`**。它在本文件夹创建独立 `.venv`，安装分享包中已固定版本的依赖，并执行离线自检；不会请求管理员权限或更改系统Python。如果提示没有Python，请先安装Python 3.10或更新版本。
3. 要使用AI质检，先复制**你自己的**完整MiMo密钥，再双击 **`配置MiMo密钥.command`**，按提示保存到当前Mac用户的系统钥匙串。此步骤不调用API。静态底线检查无需密钥。
4. 双击 **`启动质检界面.command`**，浏览器自动打开 `http://127.0.0.1:8765`。保留启动终端，文件处理过程中不要关闭它。结束时在终端按Ctrl+C。

macOS若阻止打开.command，可在Finder中右键→打开。文件不可执行时，在终端进入解压文件夹运行：

```sh
chmod +x *.command
./安装环境.command
```

## 日常操作

- **质检**：拖入XLSX、CSV、JSONL或JSON，只检查指定的Caption/人标列。默认语义辅助筛查会调用MiMo；“底线检查”只执行本地规则。遇到多个Caption列或工作表时明确选择，不改查机标、备注等其他列。
- **字段一键规范**：使用独立面板。新版12字段含画面元素；标题为 `## 字段名`（两个井号后一个半角空格），每个字段内容结束后空一行，视觉标签名 `video_similarity_tag`。新旧字段混用时优先使用非空新版字段，新版缺失或为空时回退旧字段，并提供字段版本说明。已有场景定义和编号按原文保留。缺字段题目ID与原始缺少项单独记录，不能依据缺失内容填“无”。旧任务类型没有可靠映射时保留原行并列需确认。
- **审核与返修**：自动项按白名单执行；有明确候选时先看改前/改后，再点确认。没有可靠改稿的需人工定稿。“确认”保存决定，点击“导出审核后版本”后合入新文件。可以选择“保留原文并标黄”：只保留对应问题，其余修改照常。仍有待处理项目或没有文字改动时也能导出完整表格，待处理项目按原文保留，不代表全部通过。
- **重新检测**：处理记录的“重新检测”会创建独立的新记录，保留原记录、审核决定和导出文件。语义模式会重新调用API，底线模式只执行本地规则。遇到解析版本更新提示，请重新检测后使用新结果。
- **请求进度**：运行中显示题目ID、已用时间及重试状态。单次请求最多60秒，每条AI检查连同重试最多180秒；超时后保留本地结果，标记检测未完成，其他题目继续。可在结束后点击“重试未完成项”。
- **报告**：处理记录提供简报、问题ID、检测说明、人工审核XLSX/CSV、修正副本、修改记录以及缺字段名单/明细等入口。姓名分组仅帮助定位需核对记录，疑似问题不是已确认错误。

结果默认保存在**当前使用者的 `~/Downloads`（下载）目录**，原始输入保留。上传副本、缓存和审核历史保存在本软件目录 `.local/web_jobs/`；不是服务器或多人共享服务。不要移动或覆盖正在使用的文件夹。

## 当前修改边界

基础标点、已知编号标签格式和明确的全半角规范默认自动处理；词表外错字、病句和主体引用等需确认。音频内部和画面文字默认保留，音频片段外的段尾句号仍补。画面元素为AI提供只读上下文，帮助核对引用，不允许AI直接改写该字段。属性冲突、叠词冗余、重复标签前缀不检查。检测失败、跳过和未做语义检查不算通过；只看文本无法确认视频事实。

任务类型和视听标签中的分隔符，在各标签完整且可识别时可直接规范为竖线，例如 `音色-相同，环境音-同类不同个` → `音色-相同｜环境音-同类不同个`；标签文字、顺序和内部斜杠保留。空标签、正文混入或边界不清仍需人工核对。旧审核记录中的待处理同类项可直接补齐自动修正，无需重跑API；已经做出的人工决定保持原样。

Excel输出在没有作者设备的可选渲染组件时自动使用已安装的openpyxl，保留ID文本、筛选、冻结、审核列和原文错误标红。正常报告导出不需要Node.js；可选PNG预览未随包提供。

## 常见问题

- **网页打不开/端口占用**：先确认是否已启动另一个实例。也可以在终端运行 `.venv/bin/python agent.py serve --port 8766 --open`。
- **未配置密钥**：运行配置入口。钥匙串可能弹出访问授权，请由本机用户确认；不需要把密钥发给维护人。
- **401、429或请求超时**：核对自己的密钥、额度和网络；减少并行条数，重试未完成项。启动和环境自检本身不会主动质检或重跑旧API请求。
- **无法识别Caption**：检查上传的是业务源表还是报告，明确所选列/工作表；不要把“跳过”当通过。
- **终端关闭后中断**：重新启动，刷新网页，在对应记录重试；缓存和审核记录保留。不自动重跑AI。
- **离线/没有密钥**：可以使用底线检查；语义辅助和需要AI的字段归类不能假装已完成。

## 包含的Skill与测试

`skills/deepseek-caption-review` 是WorkBuddy单段Caption自查与返修技能，独立使用说明在其目录内。`skills/caption-safe-fix` 是范围更窄的独立安全格式修正技能。两者边界以各自SKILL.md为准，不因同包而扩大权限。

开发同学可运行 `.venv/bin/python -m unittest discover -q`。包内测试仅使用合成样例，不能证明真实语义误报率。真实API调用和WorkBuddy实机安装需使用者自行试验；本包不含作者密钥、业务原表、上传历史、审核记录或虚拟环境。
