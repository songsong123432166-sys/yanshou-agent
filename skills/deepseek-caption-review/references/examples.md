# 易误伤样例

以下都是合成片段，不含生产数据。完整可运行样例在 `examples/`。

| 输入片段 | 预期行为 |
| --- | --- |
| `男子转头,随后停下.` | 改为 `男子转头，随后停下。`，不改词语 |
| `<主体1>:青年。` | 冒号改为全角；已有中文 `：` 保留 |
| `音色-相同，环境音-相同` | 标签完整时改为 `音色 - 相同｜环境音 - 相同` |
| `Hello.`、`3.14`、`https://a.test` | 英文、数值及网址内部保持；不叠加已有英文句点 |
| `##任务类型` | 改为 `## 任务类型`，保留字段值 |
| `## video_similarity_tag` | 标题改为 `## 视觉标签`，旧英文别名仍可读取 |
| `## tone`、`## scene`、`## visual_element`、`## summary` | 分别改为 `## 基调`、`## 场景`、`## 画面元素`、`## 总结` |
| `task_type` 填“多帧控制” | 明确子任务，只改标题为 `## 任务类型` |
| `subtask_type` 填“生成一段人物转头的视频。” | 明确提示语，归入 `## 提示` |
| `subtask_type` 填“人物参考｜场景参考” | 明确子任务标签，归入 `## 任务类型` |
| `task_type` 填“参考” | 原文保留，报告提供的题目ID，不猜子任务 |
| `人物参考 | 场景参考` | 改为 `人物参考｜场景参考`，竖线两侧无空格 |
| `0-8秒` | 时间范围保留写法，不自动给 `-` 两侧加空格 |
| 不足3次切镜时“第1秒，转头。第2秒，镜头切换。” | 仅在“第2秒，镜头切换”前换行，普通动作时间点不强制换行 |
| `九宫格/少宫格` | 保留任务类型，不能套成参考标签 |
| 缺少“画面元素” | 报原始缺字段，可补空标题；没有证据不填“无” |
| `主体1向前跑` | 明确裸编号补为 `<主体1>向前跑。` |
| `<主体1>说道{主体2, 眼晴}` | 内部字面内容保持；只在段尾补外层句号 |
| `说道{你好}，然后转身。` | 原样保留，不在句中大括号后补句号 |
| `说道{你好。}` | 补成`说道{你好。}。` |
| `（背景音乐是《You(=I)》, 女声唱道{Hi, 主体2!}）` | 内部括号、逗号、台词及字面主体保留；只补外层段尾标点 |
| `<环境有眼晴般的图案, 嗡嗡声>` | 音效内部保留，不做词表或中文标点替换 |
| `画面写有【眼晴 主体2, 99】` | 画面文字原样保留，不做错字/编号转换 |
| 两个场景都定义成`<场景2>`，后文引用`<场景3>` | 字段整理保留原定义与引用，不擅自改号 |
| 主体1定义中写“音色同<主体2>” | 描述内引用不是重复定义 |
| 总结用了主体2，自然指令没有主体2 | 提示自然指令漏写，不能替补动作 |
| `0-4秒……第11秒……` | 不在本技能检查时间逻辑，不自动改时间 |
| `主体穿白袍……后文写红袍` | 属性冲突停用，不借病句报告 |
| `缓缓缓缓地`、`<主体1>：<主体1>：` | 冗余、重复前缀停用，原样保留 |
| 英语对白中`me，`，建议`me,` | 只准备纯标点候选；用户核对音频并确认后才允许应用 |

用户说“只检查”时不输出已应用改稿；用户说“按Q002改”时只应用Q002，不把其他项顺手改掉。审批后其他项仍待确认，不能因为生成了副本就称全部合格。
