# WorkBuddy + DeepSeek：单段 Caption 自查

这是一套包含固定规则、Python脚本和示例的技能。一次只粘贴一段Caption；不上传表格，不需要启动网页，不需要填写本项目MiMo密钥。脚本仅使用Python 3.10+标准库，离线执行；语义检查使用WorkBuddy当前选定的模型，正常消耗该平台模型额度。

## 使用

1. 解压ZIP，保留整个 `deepseek-caption-review` 文件夹，不单独移动SKILL.md。
2. 在WorkBuddy打开这个文件夹，选用DeepSeek V4.1 Flash；对话中发送：

   > 请读取当前目录的 SKILL.md，按“Caption 单段自查与返修”规则检查下面这一段Caption，先安全修正格式，再列出待确认问题。

3. 也可通过WorkBuddy的“专家·技能·连接器 → 技能 → 添加技能 → 创建技能”入口，让它基于本目录建立本地技能；是否有直接ZIP导入入口以客户端版本为准。安装后用下面的触发语确认它实际读取了本包规则和脚本，不仅凭技能名称回答。
4. 一段检查完成后，下一段建议新建任务，避免把上段题目ID或确认意见带进来。

日常触发语：

- “检查并安全修正下面这一段Caption。”
- “只检查这段，先不要改。”
- “确认按Q002、Q004建议修改。”
- “这项没有可靠改法，保留原文，我会核对素材。”

若WorkBuddy无法运行Python，脚本步骤未完成；请技术同学配置Python 3.10+。技能不会自动安装软件，也不会暗中切换到其他API。Windows使用可用的 `python` 或 `py -3`，macOS通常为 `python3`。

## 结果

每轮新建结果目录：

- `caption.txt`：当前完整Caption，可复制；只检查模式保持原文。
- `待确认报告.md`：需要人处理的问题及具体建议，主体问题附主体原文。
- `report.json`：原文、当前稿、SHA256、自动修改、候选及确认记录。

安全修改不在人工清单中反复展示。确认建议前只是准备候选；确认后由脚本另存新版本。题目ID只使用用户提供值，Q001等是问题编号，不能当题目ID。输入始终保留。

字段标准是12字段，包含画面元素；标题使用 `## `（两个井号后一个半角空格），视觉标签名为 `video_similarity_tag`。场景定义和编号按原数据保留。加粗/转义如果只是聊天显示，不当成原表错误；不全局解码数据。

## 自测

在解压后的技能目录运行：

```sh
python3 -m unittest discover -s tests -v
python3 scripts/caption_skill.py check --input examples/caption.txt --out-dir results
```

无需模型或密钥。自测覆盖脚本行为，不能证明DeepSeek实际语义误报率。生产推广前应在团队实际WorkBuddy客户端，用人工确认的正确、错误、易误伤Caption做小规模验收；本包不声称已经替你完成客户端安装或真实模型验收。
