# 直接修正规则

快照版本9。此文件限定直接修改范围，不授权联网、上传到新服务或替换用户原文件。

## 字段与符号

| 内容 | 字段 | 写法 |
| --- | --- | --- |
| 多维标签 | 任务类型、视听标签 | `人物参考\|动态参考`、`实体/IP｜动态`；两种竖线均可。`实体/IP`、`镜头/运镜` 中的斜杠保留。 |
| 参考素材 | 输入描述、场景、主体、总结、自然指令 | `<图片X>`、`<视频X>`、`<音频X>` |
| 定义与调用 | 场景、主体、总结、自然指令 | `<场景X>`、`<主体X>`；前文定义，后文调用编号，不要求反复描述外貌。 |
| 画面文字、花字、水印 | 输入描述、画面元素、自然指令 | `【LAUNDRY】`、`【HBO】` |
| 台词、演唱、喊叫 | 自然指令（细节） | `说道{你好}`、`演唱道{오늘은 안된다고}` |
| 背景音乐及变化 | 自然指令（细节） | `（背景音乐是管弦乐，中速偏慢…）`、`（背景音乐淡出）` |
| 音效、环境声、声音起止 | 自然指令（细节） | `<传来噼啪的燃烧声>`、`<唰唰的草丛摩擦声停止>` |

合法音乐描述允许嵌套素材标签、人声和歌曲名，例如 `（背景音乐是歌曲《You(=I)》，女声演唱道{오늘은 안된다고}，营造出俏皮氛围）。` 音效尖括号内可以是整段描述，不能当作非法编号标签。

用途错配需要语境判断，不自动更换括号。普通括号、外语引号或其他字段出现合法符号本身不是错误。

## 段尾标点

任务类型、`similarity_label`、`video_similarity_tag`、`audio_similarity_tag`，以及已知同义导出字段 `task_type`、`subtask_type`、`similarity_tag`、`视听标签` 不补句号，不改标签内容。未知字段不擅自解释为元数据。

其他字段每个非空行按一段检查，空行和原空白保留；内容为“无”也需句末标点。已有 `。！？!?` 保留。人声/画面文字跨行时，不在其内容内部追加标点。

- `说道{你好}，然后转身。`：保持。
- 段尾 `说道{你好}`：补为 `说道{你好}。`。
- 段尾 `说道{你好。}`：补为 `说道{你好。}。`。
- `说道{你好}。`：不重复补。
- `{}` 或 `【】` 缺闭合符：提示核对，保留不明确的内容，不猜测闭合位置。

## 仅转人工与停用项

主体定义不能重号，编号从1连续；总结/自然指令不能引用未定义主体；每个已定义主体必须在自然指令中明确引用。描述中的“音色同<主体2>”是引用，不是重复定义。缺失主体不自动补编号或动作；对白及画面文字中的字面标签不代替实际主体引用。

错别字即使看似明显也不在这个 Skill 的直接修改范围。需要判断内容类别、改变正文词语、纠正主体映射、改多标签分隔符或补不明括号时，保留原文并列出待复核项。

属性冲突、衍字/叠词冗余和重复标签前缀不检查、不提示、不修复。不得以病句、错字或标点为名绕过停用规则。

文件无法可靠解析、Caption 列/工作表有歧义、目标格是公式、输入不属于支持的结构化 Caption 时，不修改该部分并明确标注未处理。遇到这种情况不能改查其他列。
